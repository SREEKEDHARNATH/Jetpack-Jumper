# Jetpack-Jumper

## Description

You are a little guy who have to face large obstacles but you have jetpack.
But its invisible you can see object up but not down.
You need the latest distro with updates.

## Features
* Jetpack.
* Lots of platforms.
* Difficult.
* Invisible

## Difficulties i faced
* Making the jetpack was tough since the right amount should be present
* Making the fuel indicator was challenging

## How to resolve Bugs

If you face bugs with key press restart and on run hold right arrow key sometimes it works
